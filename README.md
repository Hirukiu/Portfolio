# Portfolio — Mathieu Jin

Site portfolio personnel présentant mon parcours, mes compétences et mes projets. Réalisé dans le cadre du module Portfolio d'Epitech (B-POR-200).

## Contenu

- **Accueil** : présentation avec effet de texte animé (machine à écrire)
- **À propos** : formation, langues, centres d'intérêt
- **Compétences** : data science et IA, développement web, cybersécurité, DevOps
- **Projets** : cartes de projets avec statut et technologies
- **Contact** : liens GitHub et e-mail

## Stack technique

HTML, CSS et JavaScript natifs, sans framework ni dépendance :

- Navigation fixe qui change d'apparence au défilement
- Apparition progressive des sections avec `IntersectionObserver`
- Mise en page responsive en CSS

## Lancer le projet

Ouvrir `index.html` dans un navigateur.
